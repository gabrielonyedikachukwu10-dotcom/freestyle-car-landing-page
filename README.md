# Dream Cars Rental Services — Landing Page

A modern, responsive car rental landing page built with semantic HTML5 and vanilla CSS3. Designed with a clean aesthetic featuring interactive-ready booking tabs, categorized vehicle showcases, trending fleets, and promotional highlights.

---

##  Features

- **Hero & Search Header**: Styled navigation bar with search bar and account action buttons.
- **Dynamic Booking Bar**: Tabbed layout supporting distance, hourly, and flat-rate booking inputs.
- **Car Categories**: Visual category cards for luxury brands (Mercedes-Benz, Audi, BMW, Porsche).
- **Trend Vehicles Showcase**: Product display cards detailing car models, daily rates, and booking actions.
- **Promotional Highlights**: Dedicated section showcasing exclusive deals (e.g., 50% discount offers).
- **Responsive Layout**: Fluid UI optimized for both desktop and mobile viewports using CSS Grid and Flexbox.

---

##  Built With

- **HTML5**: Semantic markup for accessibility and search engine structure.
- **CSS3**: Custom properties (variables), modern CSS Grid, Flexbox, and media queries.
- **Google Fonts**: [Poppins](https://fonts.google.com/specimen/Poppins) for modern typography.
